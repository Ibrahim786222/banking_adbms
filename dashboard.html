ARIES Recovery Controls

ARIES Algorithm (3 Phases):
1️⃣ Analysis — Scan WAL from last checkpoint.
   Classify transactions as WINNER (committed) or LOSER (aborted).
2️⃣ Redo — Re-apply all winner transaction changes.
3️⃣ Undo — Reverse all loser transaction changes (newest first).

WAL Rule: Every procedure writes to recovery_log before modifying data — this is the Write-Ahead Log guarantee.
